# 08_Certificates

This folder contains certificates earned through the **10Pearls University Software Quality Assurance (SQA) Learning Program**.

These certificates represent the completion of training modules that were referenced and applied throughout Assignments 01–07 in this repository.

## Completed Courses

* QA Fundamentals
* Testworthy
* Postman
* JMeter
* Cypress Automation
* Selenium WebDriver & TestNG

## Purpose

The certificates are included as supporting evidence of the learning path followed during the completion of the assignments contained in this repository.

They demonstrate practical exposure to:

* Software Quality Assurance Fundamentals
* API Testing
* Performance Testing
* Test Automation
* Web Automation Frameworks
* Industry Testing Practices
